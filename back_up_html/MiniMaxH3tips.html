実行環境と必要なスペック

記事執筆時点ではComfyUI（v0.30.0〜）でのみ利用できる。

VRAM8GB、メインメモリ16GBでも動作したとの報告がある。「自分のスペックでも使えるのか」と悩む前にまず試してみるとよい。生成にかかる時間を短縮するには解像度を0.4メガピクセル未満、動画の秒数（duration）を5未満にしてみてもよい。

低スペックで動作させるとSSDにスワップが発生しSSDの寿命を削ってしまうとの懸念があるが、最近のComfyUIはメモリ管理が優秀でスワップは起きにくいとの意見もある。起動オプションに「--fast-disk」や「--disable-pinned-memory」を追加することでスワップは激減するとも。

高速化の手法

「PyTorchとCudaのバージョンアップ」「Sage Attentionのインストール」以外は、利用や併用による副作用などの懸念が払拭されていない。鉄板の高速化手法が定まるにはしばらく時間が必要と思われる。

PyTorchとCudaのバージョンアップ

2.10.0+cu130未満ならばこれ以上にするだけでかなり高速化するとの報告が複数ある。

Sage Attentionのインストール

TritonとSage Attentionをインストールする。Triton、Sage Attentionともに、現在のPyTorchやCudaのバージョンに合わせてインストールするバージョンや必要なファイルが変わってくる。
  • Sage Attentionのwhlをダウンロード https://github.com/woct0rdho/SageAttention/release...

Comfy Kitchen Attention

ComfyUIのバージョンを0.32.0以上にし、「ModelAttentionBackend」ノードを配置して「attention」の値を「comfy kitchen attention」にする。Sage Attentionとの併用は不可。Sage Attentionと比較した高速化の効果は環境によって異なり、品質はSage Attentionより高いとの話。
インストールがやや難しいSage Attentionに対して、こちらはComfyUIの標準ノードで似た効果を得られるメリットがある。

生成中の動画をプレビューする

Model Preview Overrideカスタムノードを配置する。modelにはモデルをつなぎ、「preview_frames」には動画の長さを示す「Float」に続く「数式（Math Expression）」の「整数（INT）」からつなぐ。
vaeには入力不要。生成速度は10%ほど遅くなるので、シードガチャに使うとよい。
stepが進むごとにノイズが除去されて綺麗になっていく。

UNETLoader → Sigma Shift → [MiniMax H3 Preview Override] → BasicGuider →[A]
CLIPLoader ─┐ 
VAELoader ──┴→ MiniMaxH3ReferenceToVideo → conditioning + latent →[A]
[A]→ SamplerCustomAdvanced → VAEDecode → CreateVideo → SaveVideo

連続した長尺の動画を作る方法

H3 Motion Contextは、直前の動画の文脈を引き継ぎつつ、続く動画を生成する。
ComfyUI MiniMax H3 Contex Loopという仕組みもあるが、ワークフローは分かりにくい。

MiniMax H3を画像編集モデルのように使う

Comfyui-MinimaxH3-SingleFrameは、入力画像を編集したり、2枚の入力画像をもとに中間フレームを生成したりできる。
