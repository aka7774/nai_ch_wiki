インストール

共通
  1. 実行できる環境なのかチェック
  2. 必要なソフトウェアをダウンロードする https://git-scm.com/download https://git-scm.com/download
  3. ドライバーをダウンロードする https://developer.nvidia.com/cuda-11.3.0-download-...
  4. ダウンロードに必要なアカウントを作成する　https://huggingface.co/CompVis/stable-diffusion-v1...
  5. コマンドプロンプトの起動(cmd.exe OR powershell powershellはコード実行許可の手順も)
  6. モデルのダウンロード
cmd.exe
  1. フォルダ作成
  2. cd %HOMEPATH% C:\Users\【自分のWindowsでのログイン名】に移動
  3. git clone sd-v1-4.ckpt model.ckpt モデルの名前変更
  4. RENAME sd-v1-4.ckpt model.ckpt モデルの名前変更
  5. MOVE　hoge models　モデルの移動
  6. mkdir GFPGAN
  7. cd GFPGAN
  8. git clone https://github.com/TencentARC/GFPGAN.git ダウンロード
  9. cd ..
  10. mv hoge hoge GFPGANをStable Diffusion web UIフォルダに入れる
  11. call webui-user.bat
